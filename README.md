# 활협전 대화 시현기 — 活俠傳 Dialogue Simulator

> 武俠 게임 『활협전(活俠傳)』의 대화 화면을 모사해, 직접 쓴 대본을 게임처럼 재생할 수 있는
> **팬메이드 2차 창작 도구**입니다. 설치 없이 브라우저에서 바로 동작합니다.

**▶ 바로 써 보기:** `https://5thsun1-ux.github.io/Legend-of-Mortal/` (GitHub Pages 설정 후 접속)

---

## 특징

- **원작풍 대화 연출** — 말하는 인물은 앞으로·밝게, 나머지는 뒤로·어둡게, 한 글자씩 타이핑 효과
- **대사 일괄 변환** — 소설/대본 텍스트를 붙여 넣으면 화자 자동 인식 (`[이름] = 대사` 형식 등)
- **분기 선택지** — 「당신의 선택……」 화면 + 루트1~3 + 공통루트 자동 복귀
- **사건 연출** — 책이 펼쳐지며 삽화와 세로 제목이 나타나는 장면 구현
- **회상 / 자동 재생 / 전체 화면 / 배경음(BGM)** 지원
- **5개국어 UI** — 한국어 · 日本語 · 台灣繁體 · 中国简体 · English
- **완성 작품은 단독 HTML로 남기기** — 다른 사람에게 파일 하나만 전달하면 그대로 감상 가능
- **자동 저장** — 작업 내용은 브라우저에 자동 저장, JSON 백업 지원

## 사용 방법

1. 페이지를 열고 언어를 고른 뒤, **[제목을 입력하세요]** 칸에 작품 제목을 적습니다.
2. **① 배경 선택**에서 배경을 업로드합니다.
3. **② 등장인물**에서 인물 이미지를 올립니다. 폴더째 추가하면 폴더 이름이 인물 이름이 됩니다.
4. **④ 대사 입력**에 대본을 붙여 넣고 「변환하여 추가」를 누릅니다.
5. **⑤ 재생**에서 ▶ 처음부터로 감상하고,「시현 파일 저장 (HTML)」으로 작품을 남깁니다.

자세한 기능 설명은 프로그램 각 패널의 안내문을 참고하세요.

## 저작권 안내 (중요)

- 이 저장소의 **코드와 내장 그래픽(타이틀 배경 수묵화·사건 책 SVG)은 모두 자체 제작물**입니다.
  원작 게임의 이미지 에셋은 일절 포함되어 있지 않습니다.
- 다만 이 도구는 원작 게임 『활협전(活俠傳)』의 화면 구성을 **비공식으로 모사**한 팬메이드이며,
  원작 게임의 명칭·분위기 등에 대한 권리는 원저작권자에게 있습니다.
- 도구로 제작한 결과물(시현 HTML)을 공개할 때는 원작사의 2차 창작 가이드라인을 따라 주시고,
  **개인적·비상업적 용도**로만 사용해 주세요.

## GitHub Pages로 배포하는 법

1. 이 저장소를 GitHub에 만듭니다(또는 이 파일들을 저장소 루트에 올립니다).
2. 저장소 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로 두고, Branch는 `main` / 폴더는 `/(root)` 를 선택 후 저장합니다.
4. 1~2분 뒤 `https://5thsun1-ux.github.io/Legend-of-Mortal/` 에서 바로 실행됩니다.

## 로컬에서 실행

`index.html`을 그냥 더블클릭하면 됩니다. 별도 서버·설치가 필요 없습니다.
