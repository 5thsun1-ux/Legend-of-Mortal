## 한국어

《활협전》 팬 소설과 대화극을 게임 화면 형식으로 연출하고, 여러 언어권 이용자와 공유하기 위한 **비공식 팬메이드 2차 창작 도구**입니다. 설치 없이 브라우저에서 실행되며, 전투·육성·탐색 등 원작 게임을 대체하는 기능은 포함하지 않습니다.

### 핵심 기능

- 배경·등장인물·표정·아이콘 업로드 및 무대 배치
- 대사 일괄 변환, 선택지, 공통 루트와 3개 분기 루트
- 사건 책·아이템·입퇴장·이동·흔들림·페이드 등 연출
- 엔딩 화면과 가벼운 춤 모드
- 한국어·일본어·번체·간체·영어 UI 및 고유어휘 보호 자동 번역
- 독립 HTML, JPG 장면 ZIP, 고화질/5MB WebM, 회상 대사 JPG, JSON 저장

시현기에는 원작 이미지·아이콘·음원이 포함되어 있지 않으며, 원작을 참고한 내장 데이터는 다국어 번역용 고유명사 사전입니다. 원작 및 고유명사에 관한 권리는 각 원저작권자에게 있습니다. 사용자가 추가한 자료의 권리와 이용 책임은 사용자에게 있습니다.

## English

An **unofficial, fan-made derivative-work tool** for presenting *Legend of Mortal* fan fiction and dialogue scenes in a game-screen format and sharing them across language communities. It runs directly in a browser with no installation. It contains no combat, progression, exploration, or other functionality that could replace the original game.

### Core Features

- Upload and stage backgrounds, characters, expressions, and icons
- Bulk dialogue conversion, choices, a common route, and three branch routes
- Incident books, items, entry/exit, movement, shake, and fade effects
- A custom ending screen and a lighthearted dance mode
- Korean, Japanese, Traditional Chinese, Simplified Chinese, and English UI with glossary-protected automatic translation
- Standalone HTML, JPG scene ZIP, high-quality/under-5MB WebM, recall-dialogue JPG, and JSON export

This tool contains no images, icons, or audio from the original game. The only built-in data referenced from the original work is a proper-noun glossary for multilingual translation. Rights to the original work and its terminology belong to their respective holders. Users are responsible for the rights and permitted use of anything they upload.
